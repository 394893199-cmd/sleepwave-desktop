# SleepWave 输入参数 → 声波参数映射设计

> 依据 `docs/research.md` 的声学/神经科学资料。所有映射分为三类：**生理依据映射**（有研究支持）、**启发式映射**（行业惯例/物理常识推断，标注"启发式"）、**安全边界控制**（保护听力与真实性）。

## 1. 中间量计算

### 1.1 睡眠适宜度指数（Sleep Suitability Index, SSI ∈ 0~100）

SSI 由四个子项加权合成，全部归一化到 0~100：

```
SSI = 0.45·S_time + 0.30·S_roomTemp + 0.15·S_envDiff + 0.10·S_bmi
```

**① S_time（时间节律子项，权重 0.45）**——基于褪黑素分泌与核心体温下降节律（research.md §5）：

- 理想入睡窗口（22:00–23:30）为峰值；
- 用分钟制转换：`t = 小时*60+分钟`；
- 距离理想中心（23:00）的时间偏移 `Δt = |t - 1380|`（分钟，处理跨零点取最小环距）；
- `S_time = clamp(100 - Δt * 1.6, 15, 100)`（约 62 分钟外开始衰减，白天最低 15 分，防止完全无声）。
- 白天午睡窗口（12:00–15:00）给予辅助提升：Δt2 = |t-810|，`S_time = max(S_time, 100 - Δt2*1.2)`。

**② S_roomTemp（室内温度子项，权重 0.30）**——最佳睡眠带 18–22 ℃（research.md §5）：

- `S_roomTemp = clamp(100 - |室内温度 - 20| * 12, 0, 100)`
- 例：20 ℃→100，18/22 ℃→76，26 ℃→28，30 ℃→0。

**③ S_envDiff（室内外温差子项，权重 0.15）**——启发式：室内外温差大（>8 ℃）时体感温度波动增加应激反应（research.md §5 引述），适度降温/升温环境更易入睡：

- `diff = |室内温度 - 当前温度|`
- `S_envDiff = clamp(110 - diff * 5, 20, 100)`（diff=2 ℃ 时满分，>18 ℃ 时见底）。

**④ S_bmi（BMI 子项，权重 0.10）**——BMI ≥ 28（中国标准）与中重度 OSA 相关、睡眠碎片化（research.md §6.3）：

- `bmi = 体重 / (身高/100)²`
- `S_bmi = clamp(100 - max(0, bmi - 23) * 3.6, 30, 100)`
- bmi=23→100，28→82，35→57，40→39。

**（派生提示）**：bmi ≥ 28 时 UI 显示"高 BMI 与睡眠呼吸暂停风险相关，建议就医评估"（research.md §6.3）；bmi < 18.5 提示"偏瘦，注意保暖"，不改变声波。

---

### 1.2 个性化听力系数（Individual Hearing Profile, HP ∈ 0~1）

基于年龄的高频听力衰退（research.md §6.1）与年龄-听觉上限关系（启发式插值）：

```
年龄 a（岁）：
  听觉上限 f_upper = clamp(20000 - (a - 10) * 120, 10000, 20000)   // 10 岁 ≈ 20k，60 岁 ≈ 14k，90 岁≈10.4k→下限 10k
  高频保留度 hf = clamp(1 - max(0, a - 25) * 0.016, 0.45, 1.0)     // 25 岁前 1.0，60 岁≈0.44→下限 0.45
  低频保留度 lf = clamp(1 - max(0, a - 40) * 0.006, 0.75, 1.0)     // 低频衰减少
  HP = { f_upper, hf, lf }
```

- 载波/高频组件不能超过 `f_upper`；
- 高频能量权重随 `hf` 下降，能量转投低频段；整体增益略升以补偿（但受安全上限约束）。

---

### 1.3 等效体感温度（启发式）

室内温度经体型修正（体表面积越大散热面越大，体感偏低——物理常识推断，非临床证据）：

- 体表面积 BSA（m²）：`BSA = 0.007184 · 体重^0.425 · 身高^0.725`（Du Bois 公式，医学常用）。
- `体感修正 = (BSA - 1.75) * 2.2`（℃）
- `等效体感温度 = 室内温度 + 体感修正`
- 示例：170cm/65kg → BSA≈1.75，修正≈0；180cm/90kg → BSA≈2.10，修正≈+0.8℃。

> 仅用于音色微调与 UI 提示（"体感偏暖/偏凉"），不参与安全判定。

## 2. 声波参数生成（输出）

### 2.1 目标脑波频段（决定双耳节拍差频 / 等时脉冲主频）

按 SSI 分段，实现"适宜度越高越倾向深睡 δ，越低越倾向放松 θ/α"（research.md §2.2/§3.1）：

| SSI | 目标频段 | 中心频率 f_beat | 脑状态 |
|---|---|---|---|
| ≥ 70 | δ（深睡引导） | 0.5~3 Hz 按 SSI 内插 | N3 慢波 |
| 45~69 | θ 过渡 | 4~5 Hz | 入睡期 |
| < 45 | α/θ 放松 | 6~8 Hz | 静息/午休 |

- 内插：`f_beat = lerp(0.5, 8.0, (100 - SSI)/100)`，并取整到 0.1 Hz。SSI=100→0.5Hz，SSI=50→4.25Hz，SSI=10→7.7Hz。
- 若用户选择"深睡优先"开关（UI 选项），强制映射到 δ 档（`f_beat = max(0.5, f_beat)` 且 ≤3Hz）。

### 2.2 双耳节拍（需耳机；research.md §2.2）

- 左耳载波 `fL = clamp(200, 150 + HP.f_upper*0.01, 300)` → 固定 200 Hz 基线，年龄大时略降（老化对 200Hz 感知几乎无影响，保持 200Hz 稳定）：
  - 简化：`fL = 160 Hz`（≤ 60 岁）或 `150 Hz`（> 60 岁，保护低频感知——启发式；**v1.1 音色优化：低频化降刺耳感**）。
- 右耳载波 `fR = fL + f_beat`。（听觉差频整合的物理事实）
- 峰值能量：左右各 -30 dBFS 左右（低强度，research.md §7 音量安全）。

### 2.3 等时脉冲（无需耳机；research.md §2.3/§3.2）

- 主脉冲频率 = `f_beat`（深睡档）或 `f_beat*1.5`（θ 档更快，启发式）。
- 深睡档（SSI≥70）叠加 **0.5~1 Hz 慢波节奏包络**（**类 CLAS 开环近似**，research.md §3.2：真闭环需 EEG，本软件为固定节奏近似）。
- 脉冲波形：**v1.1 柔和化**——指数衰减短音（基频 180 Hz 下滑至 90 Hz，300 ms 衰减），**50 ms 线性软起音**抑制爆音（原 300→150Hz/150ms 硬起音被反馈为"刺耳"）。

### 2.4 色噪声层（research.md §3.3/§7）

- 基底：粉红噪声 55% + 棕色噪声 45%（默认），听感柔和蓬松（**v1.1 棕噪增重：更暖更沉，降低高频刺耳感**）。
- 水温启发式：等效体感温度 < 18 ℃ → 棕噪占比升至 60%（更暖更沉）；> 24 ℃ → 粉红占比升至 70%（更轻更透气）。
- 增益 -34 dBFS 基线，随 SSI 微调（SSI 越低越需要遮盖环境噪音，clamp -28~-36）。
- 实现：Web Audio 用 `ScriptProcessor/AsyncAudio` 生成 1/f 噪声（Voss 或滤波白噪），离线预生成 10 s 缓冲循环播放，避免持续计算。

### 2.5 低频基座（低音/亚低频体感层）+ 次声层（research.md §1、§7）

- 基频 55 Hz（A1）与 40 Hz 双音，正弦，增益 -38 dBFS（极低，避免不适）。
- 频率微调启发式：男性偏低（48 Hz/36 Hz，男性体型大、低频共振感略强——启发式），女性保持 55/40。
- 等效体感温度偏低时增益 +2 dB（"暖"的听感补偿，启发式）。
- **v1.1 新增次声层**：14 Hz / 16 Hz 双正弦，增益 -42 dBFS。属人耳几乎不可闻的"超低频虚拟刺激"成分（<20 Hz 听阈极高、扬声器响应有限仅存极弱体感），不增加刺耳感。

### 2.6 高频载波 + 低频 AM 调制（「类超声」高频刺激的技术落地；research.md §4 边界、§3.4）

- **v1.1 上移至近不可听区**：`fc = clamp(f_upper - 800, 14500, 18500)`。即逼近个人高频听觉上限并下压 800 Hz 防超限：25 岁 ≈ 17.4 kHz、50 岁 ≈ 14.5 kHz、68 岁 ≈ 14.5 kHz（clamp 下限）。**不随年龄降至可闻刺耳区**（< 14.5 kHz 时强制抬高——该区间对多数成年人已接近/超出可听上限）。
- 对载波施加 `f_beat` 的 AM 调制（包络调制），即"高频载波承载低频脑波节奏"——与 MIT 40Hz 刺激的载波-调制技术路线一致（research.md §3.4），但调制频率取 δ/θ 而非 γ。
- 能量 -50 dBFS 起、随 `hf` 降低进一步衰减（`-50 - (1-hf)*8` dB）；**载波 ≥ 12 kHz 时强制 ≤ -52 dBFS**（安全上限 + 降低可闻刺耳感，research.md §7 第 4 条）。AM 调制深度 0.6。
- UI 明示："超声波无法由普通扬声器发出，本功能为高频载波调制（探索性）"（research.md §4 边界声明）。

### 2.7 主增益与时长

- 基础增益 `G = 0.22 + SSI*0.0012`（0.22~0.34 线性幅度，≈ -13~-9 dBFS）→ 推荐佩戴音量 ≤ 50 dB（research.md §3.3 白噪声 RCT 音量约定/§7 安全条）。
- 增益限制：`G*总层叠加峰值 ≤ 0.5`（-6 dBFS 峰值上限，动态压缩兜底）。
- 推荐时长：`90 分钟的整数倍`（睡眠周期，research.md §3.1）：SSI≥70→90 min；45~69→60 min；<45→30 min；用户可改。

## 5. 边界与诚实声明（UI/README 必须传达）

1. **本软件不是医疗器械**，不诊断、不治疗失眠/OSA；高 BMI/高风险者建议就医。
2. 真超声波（>20 kHz）与经颅超声神经调控**无法**由普通音频设备产生，本软件"高频"为高频载波 AM 调制（探索性）。
3. 类 CLAS 慢波脉冲为**固定节奏开环近似**，非 EEG 闭环，效果因人而异（research.md §3.2）。
4. 音量安全上限与 12 kHz 以上高频限制为硬编码保护，不可越界。
5. 性别/温感的差异映射为**启发式**，仅用于个性化微调，非临床定论。
