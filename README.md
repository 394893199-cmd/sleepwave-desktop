# SleepWave 睡眠声波生成器

根据时间、地点、环境温度与个人体型特征，个性化合成助眠声波的 Windows 桌面工程软件。通过双耳节拍、等时音、色噪声、低频次声层与近不可听区高频载波的多层复合，生成非侵入式助眠音频。

> 本软件为非医疗设备，不替代专业睡眠治疗；声波参数为固定节奏的开环近似，不作为医学诊断或治疗效果承诺。

## 核心功能

- **个性化参数输入**：时间、地点（自动天气与室温）、性别、年龄、身高、体重
- **脑波频段引导**：δ 0.5–4Hz 深睡 / θ 4–8Hz 入睡 / α 8–13Hz 放松三档，午睡窗口不引导深睡
- **多层声波复合**：双耳节拍 × 等时脉冲 × 粉红/棕噪声 × 低频次声层 × 近不可听高频载波（AM 调制）
- **安全保护**：峰值增益 ≤ 0.5 硬保护；高频载波逼近个人听觉上限且强制低增益，避免刺耳
- **实时可视化**：浏览器内声波波形绘制，支持生成、播放、停止

## 声波原理

| 层 | 参数 | 作用 |
| --- | --- | --- |
| 双耳节拍 | 左右耳差频 0.5–13Hz | 相位差引导对应脑波频段 |
| 等时脉冲 | 90–150Hz 软起音脉冲 | 节奏性听觉刺激 |
| 色噪声 | 粉红 55% / 棕 45%（随温度调整） | 掩蔽环境噪声，棕噪更暖 |
| 次声层 | 14/16Hz 正弦 @ -42dB | 不可听低频基底，增强沉浸感 |
| 高频调制载波 | 14.5–18.5kHz @ ≤ -52dB | AM 载波逼近个人听觉上限，不可闻且不刺耳 |

详细参数与公式见 [docs/design.md](docs/design.md)，调研来源见 [docs/research.md](docs/research.md)。

## 构建与运行

```bash
npm install          # 安装依赖
npm start            # 运行应用（Electron）
npm run dist         # 打包 Windows NSIS 安装包（release/）
npm run smoke        # 冒烟测试（DOM/脚本/音频层自检）
```
